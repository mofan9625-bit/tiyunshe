## 机场避坑指南与防跑路自查手册

### 识别跑路前兆的六大危险信号

跑路在灰色行业并不罕见，但绝大多数跑路在发生前 1 至 3 个月都有明显征兆：
1. **反常的“超大额超长周期促销”：** 平时月付 20 元，突然打出“100 元包三年、200 元终身无限流量”，这是运营商准备卷款前最典型的现金流回笼信号；
2. **工单回复周期断崖式延长：** 从平时的 10 分钟内响应，恶化到 3 天不回甚至直接关闭工单系统；
3. **官方 Telegram 频道禁言：** 突然开启全员禁言，或将评论区彻底关闭；
4. **核心主力节点大面积失效：** 节点从 50 个掉到只剩几个，官方以“上游机房维护”为由拖延数周不修复；
5. **频繁更换官网裸 IP：** 域名频繁被封，最后直接给出没有 SSL 证书的裸 IP 入口；
6. **运营方出现高风险违规行为：** 如允许恶意公开订阅或鼓励 BT 下载。

### 防割防坑实用防御策略

- **永远坚持月付：** 无论优惠有多诱人，新用户第一单务必从月付开始试水；
- **配置双保险组合：** 1 家高品质主力专线（如云界线） + 1 家不限时按量备用（如神行加速），即便主力临时维护也能秒级无感切换；
- **保存官方公告频道：** 第一时间关注官方 Telegram 频道，避免域名更换时因失联导致误判。

### 核心网络协议通俗对比速览

- **IEPL / IPLC（物理专线）：** 不走公网出口，点对点物理内网直通，彻底不受 GFW QoS 波动影响，成本最高，晚高峰最稳；
- **BGP 隧道中转：** 国内优质机房就近接入，经过优化隧道过境，兼具低延迟与高性价比，是目前综合表现最均衡的方案；
- **Hysteria 2（基于定制 QUIC）：** 专为恶劣高丢包网络打造，使用 UDP 传输，在弱网下抗拥塞能力极强；
- **VLESS-Reality：** 将传输层安全流量完美伪装成访问正常海外网站，握手特征极其隐蔽。

## 精选 FAQ 常见问题问答库（高频疑难解析）

<details>
<summary><b>Q1：机场、梯子与传统 VPN 到底有什么本质区别？</b></summary>

- **传统成品 VPN（如 ExpressVPN、NordVPN）：** 多采用 IPSec、WireGuard 等协议接管全设备所有网络流量。在大陆环境下其公网特征极易被识别阻断，且无法实现国内网站直连分流。
- **机场节点订阅：** 是基于 Shadowsocks、Trojan、VLESS、Hysteria 等轻量级协议的代理服务池。配合 Clash 或 Shadowrocket 等分流客户端，可以精确实现“访问百度走本地、访问 Google 走香港、访问 Netflix 走原生”，不仅速度更快，而且灵活度极高。
</details>

<details>
<summary><b>Q2：为什么很多机场白天测速飞快，一到晚上八九点就卡成 PPT？</b></summary>

因为大多数普通机场采用公网中转或廉价公网直连。白天国际出口带宽充裕，单用户享受高配额；一到晚间 20:00–23:00 黄金时段，全民上网导致骨干网发生重度拥塞，运营商 QoS 策略对跨境流量实施强制丢包限速。若服务商自身没有高成本的物理 IEPL 专线或充足的突发冗余带宽，就会发生全员卡顿。
</details>

<details>
<summary><b>Q3：新手第一次买机场，为什么强烈建议千万不要直接买年付？</b></summary>

机场行业运营受国际网络波动、域名被墙、机房迁移等多重不可抗力影响。部分低良心商家在通过超低价大促吸引大量年付后，极易出现超售劣化甚至携款跑路。选择月付，不仅可以实测该机场在你本地网络环境下的真实表现，还能将资金风险降到最低。
</details>

<details>
<summary><b>Q4：为什么客户端导入订阅后，测速全部显示 Timeout（超时或 9999ms）？</b></summary>

常见原因有四步排查法：
1. **系统本地时间误差：** 电脑或手机系统时间与标准北京时间偏差超过 60 秒，会导致 TLS 握手证书校验彻底失败。进入系统设置开启“自动同步时间”通常立竿见影；
2. **订阅未成功拉取到节点：** 检查订阅列表是否为空，若为空，可能是商家变更了订阅域名，需重新复制最新链接；
3. **安全软件/杀毒软件拦截：** 部分第三方卫士会阻断代理内核的本地回环监听端口，请将其加入白名单；
4. **套餐已欠费或流量耗尽：** 登录官网控制台检查套餐有效期与剩余流量。
</details>

<details>
<summary><b>Q5：访问 ChatGPT 提示“Access Denied”或 Claude 提示地区不受支持怎么办？</b></summary>

这是海外 AI 厂商对出口节点 IP 的风控策略所致。OpenAI 与 Anthropic 会严密监控访问者的 IP 属性，机房数据中心（Hosting）IP 极易被拒。解决方法：
1. 在客户端节点列表中选择标注为 `原生IP`、`住宅IP` 或专门的 `OpenAI / Claude` 分组节点；
2. 避免频繁切换不同国家的节点；
3. 清除浏览器对应网站的 Cookie，或使用隐私无痕窗口重新登录。
</details>

<details>
<summary><b>Q6：什么是流量倍率？为什么我买的 100G 几天就用完了？</b></summary>

倍率是服务商对不同成本节点设定的扣费系数。若节点标注为 `1.0x`，下载 1GB 扣除 1GB；若节点标注为 `3.0x`（通常是昂贵的高峰专线），下载 1GB 将在账户中扣除 3GB 流量。选购和日常使用时务必看清节点倍率，优先选择真实 1x 倍率节点。
</details>
