## 机场选择避坑指南

### 专线机场 vs 公网中转，应该怎么选？

专线（如 IEPL / IPLC）通常在晚高峰抖动、跨境拥塞和视频缓冲方面更有优势，适合 4K 流媒体、游戏和企业办公；公网中转成本通常更低，适合预算有限、轻度浏览或备用需求。选购时不要只看宣传词，最好比较晚高峰测速、丢包率、入口数量、流量倍率和退款规则。

### 为什么不建议把“直连”作为唯一方案？

单一公网直连入口更容易受到拥塞、路由波动或区域性封锁影响，故障时也缺少切换余地。更稳妥的做法是选择有多个入口 / 中转节点的服务，并保留一个不同线路的备用订阅；同时定期检查订阅有效期和节点可用性。
